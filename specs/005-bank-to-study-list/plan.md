# Implementation Plan: Add Questions to Study List from Bank Soal

**Branch**: `feat/bank-to-study-list` | **Date**: 2026-11-10 | **Spec**: [specs/005-bank-to-study-list/spec.md](file:///c:/Users/Admin/Documents/GitHub/MOCK-TEST-SSW-PM-BY-FAIZ/specs/005-bank-to-study-list/spec.md)

**Input**: Feature specification from `/specs/005-bank-to-study-list/spec.md`

## Summary

Add an interactive Study List bookmark button (`+` / `✓`) directly to each question card in Bank Soal (`.zen-q-item .zen-q-actions`), adjacent to the existing Edit, Duplicate, and Delete actions. The feature integrates with the application's existing canonical Study List architecture (`isQuestionInStudy(q)`, `makeStudyItem(q)`, and IndexedDB `studyList` store) to provide instant idempotent bookmarking (`+` adds to Study List; clicking `✓` on already-added questions never deletes), persistent state across reloads, zero duplicate entries, zero layout shifts, and non-interference with Bank Soal pagination, search, and filtering.

---

## Technical Context

**Language/Version**: Native Vanilla JavaScript (ES2022+ Native ES Modules), HTML5, CSS3.
**Primary Dependencies**: Zero external runtime dependencies. 100% native Web APIs (`IndexedDB`, `DOM`, `CustomEvent`).
**Storage**: Client-side IndexedDB (`ssw-pm-mock-test-db`, version 2) using canonical object store `studyList` with composite key `${setId}::${questionId}`.
**Testing**: Standalone Node.js test script with Chrome DevTools Protocol (`--headless=new`, `--remote-debugging-pipe`) verifying DOM mutations, IndexedDB transactions, toast notifications, sidebar counter sync, and responsive viewports (390×844 and 1440×900).
**Target Platform**: Modern mobile and desktop browsers (Android Chrome, iOS Safari, Desktop Chrome/Edge/Firefox).
**Project Type**: Single-Page Application (SPA) / Progressive Web Application (PWA).
**Performance Goals**: Sub-50ms UI response upon clicking Study List button; zero frame drops; sub-10ms in-place DOM attribute update; zero full-page re-renders.
**Constraints**: Zero changes to CBT exam engine, zero external npm libraries, zero schema migrations, preserve all existing Bank Soal filters and pagination state.
**Scale/Scope**: ~100–500 questions in Bank Soal catalog, 20 questions rendered per page; 4 action buttons per card.
